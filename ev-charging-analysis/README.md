# 전기차 충전 인프라 분석 (Snowflake)

전국 전기차 충전소 데이터를 Snowflake에서 분석해 **지역별 커버리지 격차**, **시간대 이용 패턴**,
**신규 입지 우선순위**를 도출한 프로젝트입니다.

공간 집계에는 Snowflake의 H3 육각 격자 함수(`H3_LATLNG_TO_CELL_STRING`, `H3_GRID_DISK`,
`H3_CELL_TO_POINT`)와 지리공간 함수(`ST_MAKEPOINT`, `ST_ASWKT`)를 사용했습니다.

## 분석 규모

| 항목 | 값 |
|---|---|
| 충전기 | 3,351대 |
| 충전소 | 1,457개소 |
| 충전 세션 | 92,406건 (90일) |
| 분석 지역 | 20개 시군구 |
| 총 설비용량 | 132.3 MW |

## 주요 결과

**1. 문제는 총량이 아니라 배분**

전기차 대비 충전기 비율은 전국 1:39.8로 양호하지만, 지역 간 격차가 **26배**입니다.

| 시군구 | 전기차 | 충전기 | 1대당 EV |
|---|---|---|---|
| 제주 제주시 | 21,000 | 181 | **116.0** |
| 경북 구미시 | 3,100 | 32 | 96.9 |
| 서울 강북구 | 2,400 | 30 | 80.0 |
| … | | | |
| 대구 중구 | 980 | 217 | **4.5** |

**2. 저녁 4시간에 41% 집중**

18~21시에 전체 세션의 41.2%가 몰리며 피크는 21시(12.1%)입니다.
심야(0~5시) 요금 인센티브로 수요를 분산하면 증설 없이 피크 완화가 가능합니다.

**3. 장애율 11.9%는 업계 공통 문제**

운영사 7곳의 장애율이 10.7~13.0%로 편차가 2.3%p에 불과합니다.
최대 원인은 통신이상이므로, 사업자 교체보다 통신 모듈 표준화가 효과적입니다.

**4. 신규 입지는 2트랙으로 분리**

| 트랙 | 성격 | 1위 |
|---|---|---|
| 혼잡형 | 기존 충전소 증설 | 경기 성남시분당구 (90.0점) |
| 공백형 | 신규 부지 확보 | 제주 제주시 (86.2점) |

## 실행 순서

```
sql/01_demo_data.sql          -- (선택) 데모 데이터 생성. 실데이터가 있으면 생략
sql/02_analysis.sql           -- 뷰 생성 + 분석 쿼리 1~8
sql/03_export_dashboard.sql   -- 대시보드용 JSON 추출
sql/05_site_scoring_v3.sql    -- 입지 추천 최종본
```

`02_analysis.sql` 상단의 **어댑터 레이어(0번 블록)** 에서 뷰 3개의 `FROM` 절만
실제 테이블로 바꾸면 이후 쿼리는 수정 없이 동작합니다.

```sql
CREATE OR REPLACE VIEW ... V_CHARGER AS
SELECT STAT_ID AS station_id, ...
FROM EV_ANALYTICS.RAW_EV.CHARGER_STATUS   -- ← 여기만 교체
```

## 입지 스코어링 개정 이력

초기 버전에는 구조적 편향이 있어 두 차례 수정했습니다.

| 버전 | 문제 | 수정 |
|---|---|---|
| v1 | 충전기 1대인 셀이 자동 만점 (수요갭 = EV ÷ 충전기수) | 분석 단위를 셀 → 권역(중심셀 + 인접 6셀)으로 변경 |
| v2 | 필터(권역 3대 이상)가 제주시·구미시 등 저밀도 지역을 배제 | 필터를 배제 조건이 아닌 **트랙 구분** 기준으로 전환 |
| v3 | — | 고정 임계값 대신 `PERCENT_RANK` 백분위 정규화 |

최종 배점: 지역부하(35) + 권역혼잡(25) + 급속부재(20) + 공급희소(20)

## 분석 한계

- **요일 패턴 없음** — 평일 13,160건 vs 주말 13,302건(차이 1.1%). 요일별 판단에 사용 불가
- **가동률은 시간 점유율 기준** — 완속이 높게 나오는 것은 세션이 3~8시간으로 길기 때문.
  투자 판단에는 kWh 처리량 기준을 병행해야 함
- **공백형 상위 권역의 표본이 작음** — 상위 10곳 중 6곳이 권역 충전기 1대.
  해당 가동률은 참고용이며, 순위 근거는 지역부하·공급희소 점수
- **셀 단위 수요는 세션 실적 대리변수** — 인구·상업시설 밀도 데이터 부재로
  기존 충전기가 없는 곳의 잠재 수요는 과소평가됨

## 데이터 출처

충전기 스키마는 [한국환경공단 전기자동차 충전소 정보](https://www.data.go.kr/data/15076352/openapi.do)
계열의 필드 구조(`STAT_ID`, `CHGER_ID`, `CHGER_TYPE`, `ZSCODE`, `STAT` 등)를 따릅니다.
